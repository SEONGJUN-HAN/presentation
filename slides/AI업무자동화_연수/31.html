쉬는 시간에 미리

설치 — 파일 하나 더블클릭이면 실습 준비 끝

오토핫키 · 파이썬 · Node.js · 안티그래비티 2.0 · 런처와 도구까지 한 번에 들어갑니다.
쉬는 시간에 실행했다면 4번만 확인하세요.

  1. 통합업무런처_v4.2.zip 압축 풀기 (바탕화면 등, zip 안에서 바로 실행 X)
  2. 설치하기.bat 더블클릭 → 관리자 확인 창은 예
  3. 질문 두 개에 Y — 안티그래비티 설치, 켤 때 자동 실행
  4. 트레이에 초록 H 아이콘 → Ctrl + Alt + Win + Home 으로 런처가 뜨면 끝
  파란 "Windows의 PC 보호" 창 → 추가 정보 → 실행.
설치가 막힌 PC는 화면에 나온 사이트에서 직접 깔고 한 번 더 실행.
