개념 ①

이번엔 내 PC에 '실행기'를 들입니다

코드는 그것을 읽고 움직여 줄 프로그램, 실행기가 있어야 돌아갑니다.
2시간째까지는 이미 깔려 있는 실행기를 빌려 썼습니다.

언어 실행기 하는 일 언제
VBA 엑셀 엑셀 안의 반복 작업 — 급여명세서 PDF 이미 있음
자바스크립트 브라우저 HTML 파일 하나짜리 프로그램 — 용량 줄이기 이미 있음
오토핫키 AutoHotkey 키보드 · 마우스 · 창을 대신 움직임 — 런처 본체, 에듀파인처럼 못 고치는 프로그램도 오늘 설치
파이썬 Python PDF · 엑셀 파일 처리 — 마스킹, 마트 계산기, 현황 검색 오늘 설치
자바스크립트 Node.js 브라우저 밖에서 자바스크립트 실행 — 법령 MCP처럼 AI에 붙이는 도구 오늘 설치
  쉬는 시간에 눌러 둔 설치하기.bat이 이 셋과 안티그래비티까지 한 번에 깝니다.
문법은 이번에도 외우지 않습니다. 실행기만 있으면 AI가 씁니다.
