설치 — 파일 하나 더블클릭이면 실습 준비 끝 관리자 권한 불필요

오토핫키, 편집기(Notepad++), 실습 파일 전부가 한 번에 들어갑니다.
쉬는 시간에 실행했다면 3번만 확인하세요.

  • AHK실습설치 폴더의 설치.bat 더블클릭
  • 끝나면 실습 폴더와 Notepad++(설명용_1파일.ahk)가 저절로 열립니다
  • F5 → Ctrl + Alt + M → "첫 스크립트 성공!" 알림창이면 끝
F5저장하고 실행
끄기작업표시줄 H 아이콘 우클릭 → Exit

  파란 "Windows의 PC 보호" 창 → 추가 정보 → 실행.
지우려면 제거.bat.

바탕화면 [AHK 실습 폴더] 안

문서\AHK실습\
 ├ 실전형런처.ahk  ← 실행하는 파일
 ├ 설명용_1파일.ahk  ← 문법 시연용
 ├ 기능\  런처메뉴 · 상용구 · 기타기능 …
 ├ 도구\  한글서식 · PDF정리 · 도구모음
 ├ 엑셀실습\  ← 급여명세서 VBA
 └ 통합연락처\ · 이모티콘\ · 클릭이미지\

  .ahk 우클릭 [편집]이 Notepad++ 로 열립니다.
다시 설치해도 내가 고친 파일은 그대로입니다.
