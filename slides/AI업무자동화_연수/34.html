버튼 목록은 기능\런처메뉴.ahk(99줄) 하나에 모여 있습니다.
버튼 줄에 단축키를 같이 적으면 런처를 안 열어도 바로 실행됩니다.

  • 열 파일 우클릭 → 경로로 복사

  • 받은 코드로 통째로 바꾸고 Ctrl + S → 실전형런처.ahk 에서 F5
  • 런처 버튼과 Ctrl + Alt + J 둘 다 확인
