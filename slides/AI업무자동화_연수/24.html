품의 낼 때 장바구니를 보며 옮겨 적던 목록, 북마크 한 번이면 통째로 엑셀로.
아무거나 두세 개 담으세요.

  • 상품 우클릭 → 검사 → 상품 2~3개가 함께 칠해지는 줄 → Copy outerHTML
  • 요청문 아래에 붙여넣어 AI에게 → 받은 코드 복사
  • Ctrl + Shift + B 북마크바 → Ctrl + D → 북마크 우클릭 → 수정 → URL 칸에 붙여넣기
  • 장바구니에서 북마크 클릭 → 엑셀에 Ctrl + V

  주소창에 붙여넣으면 javascript:가 지워집니다.
