언어는 AI가 통역합니다 — 말하고, 붙이고, 실행

문법은 외우지 않습니다.
우리말로 구조를 설명하면 AI가 코드로 통역합니다.

  엑셀 VBA   HTML 프로그램
① 말하기 "엑셀 VBA로 만들어줘" + 구조 설명 "HTML 파일 하나로 만들어줘" + 구조 설명
② 붙이기 Alt + F11 → 삽입 → 모듈 메모장에 붙여 .html 로 저장
③ 실행 코드 안에 커서 두고 F5 파일 더블클릭 → 브라우저에서 열림
  사람의 몫은 셋 — 구조를 정하고, 붙일 자리를 알고, 결과를 확인하기.
안 되면 오류를 그대로 붙여 "고쳐줘".
