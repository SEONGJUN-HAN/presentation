전북AI API 키 만들기

1
ai.jbe.go.kr 로그인
왼쪽 아래 API Gateway → API 키 탭
2
[API 키 생성] → 바로 복사
키 전체는 이때 한 번만 보입니다
3
품목_자동입력 설정창에 붙여넣기
AI 회사 '전북AI' 선택
4
[목록 불러오기] → 저장
모델 목록이 뜨면 키가 맞습니다
🎁 교직원 크레딧
  • 결제 등록 없이 씁니다
  • 매달 8,000크레딧 (1일 초기화)
  • 한 건에 약 1~2크레딧
🎯 안 맞을 때만 정밀
  • 합계가 다르면 [Sonnet으로 다시 분석]
  • 한 건 약 20~60크레딧
