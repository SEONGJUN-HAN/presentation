⚠️ 오해하기 쉬운 것

AI는 코드를 줄 뿐, 실행은 내 PC가 한다

✅ 좋은 소식
AI는 이미 코딩을 배우고 왔습니다
언어모델은 방대한 코드를 학습한 상태로 나옵니다.
그래서 문법을 몰라도 필요한 코드를 받아낼 수 있습니다.
비전문가에게 필요한 건 딱 두 가지
  • 언어와 편집기를 설치해 두는 것
  • 실행하는 방법을 아는 것
나머지 — 문법, 알고리즘, 에러 수정 — 은 AI가 맡습니다.
❌ 흔한 오해 — "AI가 알아서 다 해주겠지"
💬
채팅창의 AI
AI가 코드를 써 줌
내가 복사해 와야 함
코드는 '글'로 올 뿐입니다. 채팅창 안에서는 아무것도 실행되지 않습니다.
🔌
AI를 내 PC에 연결해도 (클로드 코드 등)
AI가 직접 실행까지 해 주지만, 언어가 내 PC에 깔려 있어야 돌아갑니다.
Python Node.js AutoHotkey … 없으면 실행 불가
🔑 결론: AI는 머리를 빌려주는 것이지 손발까지 빌려주지 않습니다. 언어·편집기 설치와 실행 방법 — 딱 이 준비만 해두면 나머지는 AI가 채웁니다.
