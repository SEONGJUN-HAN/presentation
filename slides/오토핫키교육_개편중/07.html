설치 — 파일 하나 더블클릭이면 실습 준비 끝 관리자 권한 불필요

오토핫키, 코드 편집기(Notepad++), 오늘 쓸 실습 파일 전부가 한 번에 들어갑니다.

  • AHK실습설치 폴더의 설치.bat 더블클릭
  • 끝나면 실습 폴더와 Notepad++(내업무도구.ahk)가 저절로 열립니다
  • F5 → Ctrl + Alt + M → "첫 스크립트 성공!" 알림창이면 끝
F5저장하고 실행
F1커서가 있는 명령어의 도움말
끄기작업표시줄 H 아이콘 우클릭 → Exit

  파란 "Windows의 PC 보호" 창 → 추가 정보 → 실행. 지우려면 제거.bat.
