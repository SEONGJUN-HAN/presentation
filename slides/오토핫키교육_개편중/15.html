런처 속을 열어 보면 — 목록 한 줄이 버튼 하나 가볍게 보고 넘어가기

버튼 12개를 하나씩 다 쓰면 화면을 넘어갑니다

그래서 버튼을 목록에 적어두고, 만드는 코드는 한 벌만 써서 돌립니다.

  • 버튼 하나가 목록 한 줄로 줄어듭니다
  • for 가 목록을 돌면서 버튼을 대신 만들어 줍니다
  • .Bind(it) — 그 줄의 값으로 고정 (없으면 전부 마지막 것만 열림)

  잠시 뒤 AI에게 버튼을 시키면 바로 이 목록에 한 줄이 늘어납니다. 나머지는 그냥 두고 넘어가세요. 

; 실전형런처.ahk 안의 BuildMyMenu()
; ▼ 여기만 바꾸세요 — 한 줄이 버튼 하나
g := { col: 2, title: "내가 자주 쓰는 것", items: [] }
g.items.Push({ key: "W", label: "네이버", run: g_PathNaver })
m.Push(g)
;      ↑ col 숫자만 바꾸면 다른 열로 옮겨갑니다
; ↓ 아래는 그대로 — 목록을 읽어서 대신 만듭니다
for grp in BuildMyMenu()      ; ① 그룹을 하나씩
{
    lg.AddText(opt . " w280", grp.title)
    for it in grp.items       ; ② 그 안의 버튼
    {
        btn := lg.AddButton("xp y+4 w280 h31",
               it.label . " (&" . it.key . ")")
        btn.OnEvent("Click", RunMenuItem.Bind(it))
    }
}
