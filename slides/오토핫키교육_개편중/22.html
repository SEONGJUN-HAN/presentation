집중 실습 ②. 북마클릿 — 11번가 장바구니를 엑셀로 설치 0

물품 품의 낼 때 장바구니를 보며 하나씩 옮겨 적으셨죠? 북마크 한 번이면 목록이 통째로 엑셀로. 로그인 안 해도 됩니다. 아무거나 두세 개 담으세요.

  • 상품 한 줄 우클릭 → 검사 → 상품 한 줄이 통째로 칠해지는 줄 찾기 → 우클릭 Copy → Copy outerHTML
  • 요청문 아래에 붙여넣어 AI에게 → 받은 코드 복사
  • Ctrl + Shift + B 북마크바 → Ctrl + D → 북마크 우클릭 → 수정 → URL 칸에 붙여넣기
  • 장바구니에서 북마크 클릭 → 엑셀에 Ctrl + V

  주소창에 붙여넣으면 javascript:가 지워집니다. 반드시 북마크 수정 화면에서!
