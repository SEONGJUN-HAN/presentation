실습 ③. 상용구도 AI에게 — 내 것으로 바꾸고 하나 더 직접 해보기

파일이 짧을수록 AI가 정확합니다. 상용구만 모아 둔 기능\기본단축키.ahk(61줄)를 통째로 맡깁니다.

이렇게 합니다

  • 기본단축키.ahk 우클릭 → 편집 → Ctrl + A Ctrl + C → 요청문 아래에 붙여넣기
  • 받은 코드로 통째로 바꾸고 Ctrl + S
  • 실전형런처.ahk 탭으로 가서 F5 → 메모장에 /bank

  기능\ 파일에서 F5를 누르면 그 파일만 따로 켜집니다. 실행은 언제나 실전형런처.ahk 에서.

  Ctrl + Alt + H 목록에 새 상용구가 보이면 끝. 

; (AI 채팅창에 이렇게)

아래는 내 AutoHotkey v2 상용구 파일이야.

1. 전화번호·이메일·인사말·서명을
   내 정보로 바꿔줘.
   (이름: ○○○ / ○○학교 행정실
    / 063-000-0000)
2. /bank 를 치면 우리 학교 계좌가
   들어가는 상용구를 하나 추가해줘.
3. 새로 넣은 줄 옆에는 ; 설명을 달아줘.
4. 파일 전체를 다시 보여줘.
