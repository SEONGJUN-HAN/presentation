집중 실습 ①. 엑셀 VBA — 급여명세서를 개인별 PDF로 설치 0

명세 시트의 이름 칸(F4)만 바꾸면 한 사람 명세서가 채워지는 파일입니다. 이름을 하나씩 넣고 PDF로 저장하는 일을 20명이든 200명이든 한 번에.

이렇게 합니다

  • 실습 폴더 엑셀실습\ 의 파일을 열고 두 시트를 훑어보기
  • 요청문을 AI에게 → 받은 코드 복사
  • Alt + F11 → 삽입 → 모듈 → 붙여넣기 → F5
  • 바탕화면 명세서 폴더에서 PDF 몇 개 열어 숫자 맞는지 확인

  확인은 우리 몫 — 숨겨 둔 퇴사자까지 나왔거나 소계 행이 섞였으면 "○○가 나왔어, 빼줘". 매크로 저장은 안 해도 됩니다(닫을 때 아니요). 

' (AI 채팅창에 이렇게)

엑셀 VBA 코드를 만들어줘.

'급여명세' 시트 F4에 이름을 넣으면
그 사람 명세서가 채워져.

'급여명세' 시트를 PDF로 저장해줘.
