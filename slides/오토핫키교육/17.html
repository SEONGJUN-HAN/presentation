8. Clipboard (복사 & 붙여넣기)

한글은 클립보드로!

핫스트링으로 한글 문장을 그냥 타이핑하면 IME 때문에 글자가 깨질 수 있습니다.

  • 영문·숫자는 그냥 타이핑해도 OK
  • 한글은 클립보드에 담아 ^v 로 붙이면 안 깨짐
  • `n : 엔터(줄바꿈) 역할 
; ❌ 한글을 그냥 타이핑 → 깨질 수 있음
::/hi::안녕하세요. 홍길동입니다.
;   → "안녕하8요" 처럼 깨짐

; ✅ 클립보드에 담아 붙여넣기 → 안 깨짐
::/hi::
    Clipboard := "안녕하세요. 홍길동입니다."
    Send, ^v
Return
