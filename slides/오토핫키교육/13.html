10. #IfWinActive (충돌 방지)

스마트한 상황별 단축키

특정 앱에서만 단축키가 작동하도록 제한합니다.

  • 프로그램 간 단축키 충돌 방지
  • 작업 효율의 극대화
  • 반드시 닫기(#IfWinActive) 필수 
; 크롬이 활성화되었을 때만 작동
#IfWinActive, ahk_exe chrome.exe

^!s::
    Send, ^l ; 주소창 선택
    Sleep, 200
    Send, https://www.google.com{Enter}
Return

; 제한 종료 (반드시 닫아주기)
#IfWinActive
