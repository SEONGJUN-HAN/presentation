9단계. 경로는 위로, 오류는 친절하게 계속 쓸 수 있게

내일도 쓰려면 이 두 가지가 필요합니다

오늘 만든 런처가 다음 주에도 살아 있게 하는 마지막 손질입니다.

  • 경로를 맨 위에 모읍니다 — PC를 바꾸거나 폴더를 옮겨도 여기만 고치면 됩니다
  • 없는 파일이면 알려줍니다 — Run 은 경로가 틀려도 아무 말도 안 합니다
  • RunTarget 은 "어디를 고치면 되는지"까지 말해 줍니다

  "눌러도 아무 일이 없다"로 30분을 태우는 지점이 여기입니다. 그리고 여기까지가 강사 런처의 골격 전부입니다. 

; ▼ 경로는 맨 위에 모아 둡니다
global g_PathLog  := "C:\업무\업무일지.xlsx"
global g_PathNeis := "https://www.neis.go.kr"
; ▼ 없으면 어디를 고칠지 알려주고 엽니다
RunTarget(target)
{
    isUrl := (SubStr(target, 1, 4) = "http")
    if (!isUrl && !FileExist(target))
    {
        MsgBox("경로가 없습니다.`n`n" . target
             . "`n`n[9단계]를 고쳐 주세요.")
        return
    }
    try Run(isUrl ? target : '"' . target . '"')
    catch
        MsgBox("실행할 수 없습니다.")
}
