응용 ②. 엑셀 VBA — 급여명세서 개인별 PDF 오토핫키 밖으로

같은 방식이 엑셀에서도 통합니다(VBA는 엑셀에 이미 있어 설치 불필요). 비결은 말로 설명하지 말고 화면을 보여주는 것.

엑셀을 AI에게 '보여주기'

  • 시트를 Win + Shift + S 로 캡처해 채팅창에 Ctrl + V (가장 확실 ★)
  • 받은 코드는 개발 도구 → Visual Basic → 삽입 → 모듈에 붙여넣고 F5
  • 반드시 사본으로 먼저, 저장은 매크로 사용 통합 문서(.xlsm)

  실제 급여·주민번호는 올리지 마세요. 가상 데이터로 코드만 받아 내 파일에 적용. 

; (시트 캡처를 붙여넣은 뒤 이렇게)
