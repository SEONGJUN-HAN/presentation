9단계. 경로 설정이 없었던 이유 — A_ScriptDir 폴더째 가져가기

"이 파일이 들어 있는 폴더"

C:\Users\한성준\... 라고 적었으면 여러분 PC에서 전부 깨졌을 겁니다. 내 위치를 기준으로 적으면 어디에 두든 그대로 돌아갑니다.

오토핫키연수_배포\
  ├── 내업무도구.ahk  ← A_ScriptDir 은 여기
  ├── 도구\  한글서식 · PDF정리 · 도구모음
  ├── 이모티콘\
  └── 통합연락처\

  이 폴더를 통째로 USB에 복사해서 사무실 PC에 붙여넣으세요. 설치도 설정도 없이 그 자리에서 바로 돌아갑니다. 

; A_ScriptDir = 이 파일이 있는 폴더
global g_ToolDir := A_ScriptDir . "\도구"
global g_PathToolBox := g_ToolDir . "\도구모음.html"

; ▼ 내 것만 여기서 바꾸면 됩니다
global g_PathNaver := "https://www.naver.com"

; 없으면 어디를 고칠지 알려주고 엽니다
RunTarget(target)
{
    if (InStr(target, ":\") && !FileExist(target))
    {
        MsgBox("경로가 없습니다.`n`n" . target)
        return
    }
    Run(target)
}
