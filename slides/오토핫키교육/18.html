부팅 시 자동 실행 등록

shell:startup 이란?

윈도우가 켜질 때 자동으로 실행되는 프로그램 폴더입니다. 여기에 .ahk 파일의 바로가기를 넣어두면 부팅 시마다 자동으로 핫키가 활성화됩니다.

등록 방법

  • 1 윈도우 키 + R → 실행창 열기
  • 2 shell:startup 입력 후 엔터
  • 3 등록할 .ahk 파일 우클릭 → 바로가기 만들기
  • 4 생성된 바로가기를 startup 폴더로 이동

 바로가기를 넣는 이유 — 원본 파일 수정 시 항상 최신 내용이 자동 반영됩니다.

 파일 수정 후에는 트레이 아이콘 우클릭 → Reload This Script로 즉시 적용. 재부팅 불필요!
