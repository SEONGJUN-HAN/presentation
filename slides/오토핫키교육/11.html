Ctrl + Alt + L 로 여는 내 런처 + 상용구(/tel, /hi)까지 파일 하나

0~6단계는 직접 만드는 곳, 7~9단계는 이미 만들어져 있는 걸 눌러보는 곳입니다.

이 순서대로 만들어 갑니다

단계 만드는 것 배우는 명령어
0내 첫 알림창MsgBox
1맛보기 단축키핫키 · Run
2런처 창 띄우기Gui · 버튼
3버튼 늘리기두 줄 복사 · 경로
4상용구핫스트링
5한글 상용구A_Clipboard · Send
6일하는 버튼Sleep · Send
7받은 런처 써 보기— 이해 안 해도 됨
8목록으로 묶기이중 for · Bind
9폴더째 가져가기A_ScriptDir
클릭 1~3마우스 대신 누르기Click · Sleep · ImageSearch

  실습 파일의 [N단계] 주석이 이 표와 똑같이 매겨져 있습니다.
