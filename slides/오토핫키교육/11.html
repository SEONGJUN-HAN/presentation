1단계. 단축키 + Run — 뭐든 한 방에 열기 런처의 씨앗

단축키 한 줄이면 열립니다

Run은 프로그램·파일·폴더·사이트를 가리지 않습니다.

^ (Ctrl)  |  ! (Alt)
+ (Shift)  |  # (Win)
  • ^!n = Ctrl + Alt + N
  • 끝에는 항상 Return

  그런데 열 게 10개면 단축키도 10개? 그래서 다음 단계, 런처 창입니다. 

; Ctrl + Alt + N → 나이스 열기
^!n::
    Run, https://www.neis.go.kr
Return

; 파일·폴더도 똑같이 됩니다
^!e::
    Run, C:\Users\내이름\Documents\업무일지.xlsx
Return
