7단계. 버튼에 단축키 달기 — key 한 칸 추가 여기부터 키우기

지금부터 목록에 칸을 하나씩 더 붙여 강사 런처의 골격까지 갑니다. 코드 구조는 하나도 안 바뀝니다.

마우스로 찾아 누르면 런처가 아깝습니다

창을 띄우고 → 눈으로 찾고 → 클릭. 그러면 결국 바탕화면 아이콘과 같습니다. 손이 키보드를 떠나지 않게 만들어 봅시다.

  • 목록 한 줄에 key: "1" 만 추가
  • 버튼 글자 뒤에 (&1) 을 붙여서 만들기
  • & 는 윈도우에게 "Alt + 이 글자로 누를 수 있다"고 알리는 표시

  Ctrl+Alt+Shift+L → Alt+1 — 창이 뜨자마자 보지도 않고 실행. 한 런처 안에서 key 는 서로 다르게. 

; 지금까지 (3단계)
{ label: "업무일지", run: g_PathWorkLog }

; key 한 칸만 추가하면
{ key: "1", label: "업무일지", run: g_PathWorkLog }
  ↑ Alt + 1 로 바로 실행


; 버튼 만드는 곳도 딱 한 줄만 바뀝니다
btn := lg.AddButton("w220 h36",
        it.label . " (&" . it.key . ")")
;                    ↑ 여기가 Alt 표시

btn.OnEvent("Click", RunMenuItem.Bind(it))
;                  ↑ 3단계와 똑같은 Bind
