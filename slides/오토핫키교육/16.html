6단계. 일하는 버튼 — Sleep & Send 런처 업그레이드

여는 버튼 → 일하는 버튼

버튼이 프로그램을 열고, 기다렸다가, 대신 입력까지 합니다.

  • Sleep, 1000 = 1초 대기 — 창이 뜨기 전에 입력하면 사라지므로 기다림이 필수
  • Send, ^v = 키보드 대신 눌러주기 (5단계 클립보드 방식 재활용)

  실험 — Sleep을 0으로 바꿔 실행해 보세요. 입력이 사라지죠? 그게 Sleep이 필요한 이유입니다. 

; 런처 버튼: 📝 메모장 열고 할 일 쓰기
Gui, Add, Button, w260 gMacro1, 📝 메모장 열고 할 일 쓰기

Macro1:
    Gui, Destroy
    Run, notepad.exe
    Sleep, 1000   ; 메모장이 뜰 때까지 대기
    Clipboard := "📌 오늘 할 일`n1. `n2. "
    Send, ^v
Return
