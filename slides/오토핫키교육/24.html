8단계. 어떻게 만들었나 — 목록으로 묶었을 뿐 가볍게 보고 넘어가기

버튼 12개를 두 줄씩 쓰면 24줄입니다

그래서 버튼을 목록에 적어두고, 만드는 코드는 한 벌만 써서 돌립니다.

  • 버튼 하나가 목록 한 줄로 줄어듭니다
  • for 가 목록을 돌면서 버튼을 대신 만들어 줍니다
  • .Bind(it) — 버튼마다 그 줄의 값으로 고정 (없으면 전부 마지막 것만 열립니다)

  Bind 가 바로 안 와닿아도 괜찮습니다. 편하려고 넣은 부분이니 그냥 두고 넘어가세요. 

; ▼ 여기만 바꾸세요 — 한 줄이 버튼 하나
g := { title: "내가 자주 쓰는 것", items: [] }
g.items.Push({ key: "W", label: "네이버",
               run: g_PathNaver })
m.Push(g)

; ↓ 아래는 그대로 — 목록을 읽어서 대신 만듭니다
for grp in BuildMyMenu()      ; ① 그룹을 하나씩
{
    lg.AddText("xm y+14", grp.title)
    for it in grp.items       ; ② 그 안의 버튼
    {
        btn := lg.AddButton("xm w280 h34",
               it.label . " (&" . it.key . ")")
        btn.OnEvent("Click", RunMenuItem.Bind(it))
    }
}
