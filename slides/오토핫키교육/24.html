응용 ③. 자바스크립트 — 장바구니를 엑셀로 설치 0

물품 구매 품의 낼 때, 장바구니를 보며 하나씩 옮겨 적으셨죠? 북마크 하나로 표가 통째로 복사됩니다. 설치도, 프로그램도 필요 없습니다.

북마클릿 = 북마크에 담은 코드

  • 아무 페이지나 Ctrl + D 로 북마크 → 이름은 "장바구니→엑셀"
  • 북마크 우클릭 → 수정 → URL 칸에 AI가 준 코드 붙여넣기
  • 11번가 장바구니에서 원하는 것만 체크 → 북마크 클릭 → 엑셀에 Ctrl + V

  주소창에 붙여넣으면 javascript:가 지워집니다. 반드시 북마크 수정 화면에서!
