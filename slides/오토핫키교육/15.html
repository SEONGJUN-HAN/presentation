3단계. 버튼을 내 것으로 — 경로 바꾸기 내 런처 완성

바꿀 곳은 딱 두 군데

  • 버튼 이름 — 내 업무 이름으로
  • Run 뒤의 경로 — 내가 여는 파일·폴더·사이트로

  경로 따는 법 — 파일을 Shift + 우클릭 → "경로로 복사"

  고친 뒤에는 F5 (또는 트레이 우클릭 → Reload This Script) 

; ▼ 여기만 바꾸세요 ① — 버튼 이름
Gui, Add, Button, w260 gRun1, 📄 업무일지 열기
Gui, Add, Button, w260 gRun2, 🌐 나이스 접속

; ▼ 여기만 바꾸세요 ② — 여는 대상
Run1:
    Gui, Destroy
    Run, C:\Users\내이름\Documents\업무일지.xlsx
Return

; Run2, Run3 … 도 같은 방식
