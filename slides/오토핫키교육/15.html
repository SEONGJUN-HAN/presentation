3단계. 버튼 늘리기 — 한 덩어리가 버튼 하나 내 런처 완성

이름을 붙일 것도 없습니다

버튼을 만들고, 만든 그 자리에 바로 이어서 할 일을 붙입니다. 외울 것도, 새로 배울 것도 없습니다.

  • AddButton — 버튼을 만든다 (따옴표 안의 글자만 바꾸기)
  • .OnEvent — 이어서 누르면 할 일 (경로만 바꾸기)
  • 한 덩어리를 통째로 복사해 붙여넣으면 버튼이 하나 더

  경로 따는 법 — 파일 Shift + 우클릭 → "경로로 복사". 고친 뒤에는 Ctrl + F9. 

; ▼ 여기만 바꾸세요 — 한 덩어리가 버튼 하나
g_Gui.AddButton("w280 h34", "📄 업무일지")
    .OnEvent("Click", (*) => (g_Gui.Destroy(),
        Run("C:\업무\일지.xlsx")))

g_Gui.AddButton("w280 h34", "🌐 네이버")
    .OnEvent("Click", (*) => (g_Gui.Destroy(),
        Run("https://www.naver.com")))

; ↑ 통째로 복사해 붙여넣으면 버튼이 하나 더

; g_Gui.Destroy() = 창을 닫아라
; Run(...) = 이걸 열어라
