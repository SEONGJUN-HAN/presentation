3단계. 버튼 늘리기 — 두 줄 복사가 전부 내 런처 완성

버튼 하나가 두 줄입니다

외울 것도, 새로 배울 것도 없습니다. 두 줄을 복사해서 이름만 바꾸면 버튼이 늘어납니다.

  • 첫 줄 — 버튼을 만든다 (따옴표 안의 글자만 바꾸기)
  • 둘째 줄 — 누르면 뭘 열지 (경로만 바꾸기)
  • b1 → b2 → b3 … 이름만 겹치지 않게

  경로 따는 법 — 파일 Shift + 우클릭 → "경로로 복사". 고친 뒤에는 Ctrl + F9. 

; ▼ 여기만 바꾸세요 — 버튼 하나가 두 줄
b1 := g_Gui.AddButton("xm w280 h34", "📄 업무일지")
b1.OnEvent("Click", (*) => OpenIt("C:\업무\일지.xlsx"))

b2 := g_Gui.AddButton("xm w280 h34", "🌐 네이버")
b2.OnEvent("Click", (*) => OpenIt("https://www.naver.com"))

; ↑ 이 두 줄을 복사해 붙여넣고 b3, b4 …

; ↓ 아래는 그대로 두세요 (한 번만 만들어 둡니다)
OpenIt(target)          ; 런처를 닫고 → 엽니다
{
    CloseLauncher()
    Run(target)
}
