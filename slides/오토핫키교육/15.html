3단계. 버튼 목록 만들기 — 한 줄 = 버튼 하나 내 런처 완성

버튼을 늘리는 법

코드를 여러 번 쓰지 않습니다. 목록에 한 줄만 더 적으면 됩니다.

  • label — 버튼에 보일 글자
  • run — 열고 싶은 파일 · 폴더 · 사이트
  • Bind — 버튼마다 그 줄의 값으로 고정

  경로 따는 법 — 파일 Shift + 우클릭 → "경로로 복사"

  고친 뒤에는 Ctrl + F9 로 다시 실행 

; ▼ 여기만 바꾸세요 — 한 줄이 버튼 하나
buttons := [
  { label: "📄 업무일지", run: "C:\업무\일지.xlsx" },
  { label: "🌐 나이스",  run: "https://neis.go.kr" }
]

; ↓ 아래는 그대로 두세요
for b in buttons {
    btn := myGui.AddButton("w260", b.label)
    btn.OnEvent("Click", OpenIt.Bind(b.run))
}
