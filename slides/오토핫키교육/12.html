2단계. 런처 창 띄우기 — Gui 오늘의 핵심

버튼 모음 창 = 런처

딱 세 가지만 알면 창이 만들어집니다.

  • Gui, Add, Button — 버튼 추가
  • gRun1 — 버튼을 누르면 Run1: 으로 점프
  • Gui, Show — 창 보여주기

  F5 실행 → Ctrl + Alt + L → 내 런처 창이 처음으로 뜹니다! 

; Ctrl + Alt + L → 런처 창
