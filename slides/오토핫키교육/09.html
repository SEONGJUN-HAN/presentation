AI로 코딩하기 (바이브코딩) 오늘의 방식

외우지 않습니다. 시킵니다.

코드는 AI가 만들고, 우리는 실행하고 고치는 법만 배웁니다.

  • 요청 — "AutoHotkey v2 문법으로 ○○을 하는 코드를 짜줘"라고 원하는 동작을 설명
  • 실행 — 코드를 VS Code에 붙여넣고 Ctrl+F9로 바로 실행
  • 수정 — 에러 메시지를 그대로 복사해 AI에 붙여넣고 "이 오류 고쳐줘"

 AI가 옛 버전(v1) 문법을 주는 것이 실패 1순위! 항상 "v2로"를 명시하세요. 

; ── AI에게 이렇게 요청하세요 ──
