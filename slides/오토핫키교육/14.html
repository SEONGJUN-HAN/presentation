2단계. 런처 창 띄우기 — Gui 오늘의 핵심

버튼 모음 창 = 런처

창을 만들고 → 붙이고 → 보여주면 끝입니다.

  • Gui() · .AddButton() — 창 만들고 버튼 붙이기
  • .OnEvent("Click", …) — 누르면 할 일 연결
  • .Show() — 창 보여주기

  Ctrl + F9 실행 → Ctrl + Alt + L → 내 런처 창이 처음으로 뜹니다! 

; Ctrl + Alt + L → 런처 창
^!l::
{
    ; 창 만들기 (제목: 나만의 런처)
    myGui := Gui(, "나만의 런처")
    myGui.AddText(, "원하는 버튼을 누르세요")
    ; 버튼 붙이고, 누르면 할 일 연결
    btn := myGui.AddButton("w260", "🌐 나이스 접속")
    btn.OnEvent("Click", (*) => Run("https://www.neis.go.kr"))
    myGui.Show()          ; 화면에 보여주기
}
