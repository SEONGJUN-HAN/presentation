8단계. 버튼이 많아지면 — 그룹으로 묶기 목록을 한 겹 감싸기

버튼이 많아지면 뭐가 뭔지 모릅니다

목록을 그룹으로 한 겹 감싸면 끝입니다.

  • { title, items } — 무슨 제목으로 어떤 버튼들
  • for 가 두 겹이 됩니다 — 한 겹 감쌌으니 꺼낼 때도 한 겹 더
  • xm 만 붙이면 오토핫키가 알아서 아래로 쌓아 줍니다 (2단계와 같은 방식)

  강사 런처도 여기까지가 전부입니다. 거긴 좌표를 계산해 3열로 나누는 코드가 더 붙어 있을 뿐입니다. 

; ▼ 여기만 바꾸세요 — 그룹 하나가 이렇게
g := { title: "문서·폴더", items: [] }
g.items.Push({ key: "1", label: "업무일지",
               run: g_PathWorkLog })
; (한 줄 더 붙이면 버튼 하나 더)
m.Push(g)

; ↓ 아래는 그대로 — for 가 두 겹이 됩니다
for grp in BuildMyMenu()      ; ① 그룹을 하나씩
{
    lg.AddText("xm y+14", grp.title)
    for it in grp.items       ; ② 그 안의 버튼
    {
        btn := lg.AddButton("xm w280 h34", ...)
        btn.OnEvent("Click", RunMenuItem.Bind(it))
    }
}
