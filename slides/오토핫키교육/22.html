8단계. 버튼이 많아지면 — 그룹과 열 목록을 한 겹 감싸기

버튼이 많아지면 화면을 넘어갑니다

창 그리는 코드는 그대로. 목록을 그룹으로 한 겹 감싸면 끝입니다.

  • { col, title, items } — 몇 번째 열에 무슨 제목으로 어떤 버튼들
  • for 가 두 겹이 됩니다 — 그룹을 돌고, 그 안의 버튼을 돕니다
  • 좌표 계산은 그대로 두세요 — 버튼이 2개든 30개든 안 고칩니다

  이게 강사 런처와 똑같은 구조입니다. 거긴 열이 3개일 뿐입니다. 

; ▼ 여기만 바꾸세요 — 그룹 하나가 이렇게
g := { col: 1, title: "문서·폴더", items: [] }
g.items.Push({ key: "1", label: "업무일지",
               run: g_PathWorkLog })
; (한 줄 더 붙이면 버튼 하나 더)
m.Push(g)

; ↓ 아래는 그대로 — for 가 두 겹이 됩니다
for grp in BuildMyMenu()      ; ① 그룹
{
    lg.AddGroupBox(..., grp.title)
    for it in grp.items       ; ② 그 안의 버튼
        btn.OnEvent("Click",
                    RunMenuItem.Bind(it))
}
