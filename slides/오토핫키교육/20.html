클릭 3단계. 좌표 대신 그림을 찾아 누르기 창이 움직여도 맞는다

좌표는 창만 옮겨도 깨집니다

"이 그림이 있는 자리"를 찾아서 누르면 창이 어디에 있든 맞습니다. 이게 실전에서 쓰는 방식입니다.

  • Win + Shift + S 로 버튼만 잘라 복사
  • mspaint → Ctrl+V → Ctrl+S 로 클릭이미지 폴더에 PNG 저장
  • 파일 이름만 코드에 적으면 끝

  투명 배경 PNG는 못 찾습니다(그림판으로 저장). 화면 배율이 다른 PC의 그림도 안 맞으니 내 PC에서 내가 캡처하세요. 

; [클릭 3] 그림 찾아 누르기 : Ctrl + Alt + V
; ▼ 여기만 바꾸세요 (저장한 파일 이름)
^!v::ClickImage("계산기_5.png")

ClickImage(fileName)
{
    imgPath := A_ScriptDir . "\클릭이미지\" . fileName
    ; *50 = 색이 조금 달라도 같은 것으로
    found := false
    try found := ImageSearch(&fx, &fy,
        0, 0, A_ScreenWidth, A_ScreenHeight,
        "*50 " . imgPath)
    if found
        Click(fx + 10, fy + 10)   ; 찾은 자리를 누름
    else
        MsgBox("그 그림을 못 찾았습니다.")
}
