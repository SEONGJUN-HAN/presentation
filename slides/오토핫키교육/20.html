참고. 창 다루기 — 더 깊이 가면 참고

오늘 런처엔 없지만, 알아두면 좋은 두 가지

  • WinActivate — 창 제목으로 원하는 창을 맨 앞으로 (해상도와 무관해 안정적)
  • #IfWinActive — 특정 프로그램에서만 단축키가 작동 (충돌 방지)

  필요해지면 외울 필요 없이 — "AI에게 v1 문법으로 짜달라"고 하면 됩니다. 다음 슬라이드에서 그 방법을 실습합니다. 

; 메신저 창을 맨 앞으로
^!w::
    WinActivate, JBEdu Messenger+
Return

; 크롬에서만 작동하는 단축키
#IfWinActive, ahk_exe chrome.exe
^!s::
    Send, ^l
    Send, https://www.google.com{Enter}
Return
#IfWinActive   ; 제한 닫기 (필수)
