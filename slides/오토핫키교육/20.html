클릭 3단계. 좌표 대신 그림을 찾아 누르기 창이 움직여도 맞는다

좌표는 창만 옮겨도 깨집니다

"이 그림이 있는 자리"를 찾아서 누르면 창이 어디에 있든 맞습니다. 세 줄이면 됩니다.

  • Win + Shift + S 로 버튼만 잘라 복사
  • mspaint → Ctrl+V → Ctrl+S 로 PNG 저장
  • 저장한 파일 Shift + 우클릭 → "경로로 복사" → 따옴표 안에 붙여넣기

  투명 배경 PNG는 못 찾습니다(그림판으로 저장). 화면 배율이 다른 PC의 그림도 안 맞으니 내 PC에서 내가 캡처하세요. 

; [클릭 3] 그림 찾아 누르기 : Ctrl + Alt + V
^!v::
{
    ; ▼ 여기만 바꾸세요 ("경로로 복사" 붙여넣기)
    ImageSearch(&x, &y,
        0, 0, A_ScreenWidth, A_ScreenHeight,
        "C:\Users\내이름\Pictures\계산기_5.png")
    MouseMove(x, y)      ; 그 자리로 옮기고
    Click()              ; 누른다
}

; ImageSearch — 그림을 찾아 x, y 에 담아라
; MouseMove   — 그 자리로 옮겨라
; Click       — 거기를 눌러라
; 못 찾으면 MouseMove 에서 멈추고
; 오류창이 뜹니다. 마우스가 안 움직이니
; 엉뚱한 데가 눌릴 일은 없습니다.
