직접 AI에게 시켜보기 (바이브코딩 실전) 직접 해보기

이미 만든 편리한 프로그램(.exe · 로컬 html)을, 백지에서 짜지 말고 있는 런처에 '버튼 + Run'만 AI로 추가해 연결합시다.

이렇게 시킵니다

  • 런처(내업무도구.ahk) 코드 전부 복사 → AI에 붙여넣기
  • "이 프로그램 여는 버튼과 Run 추가해줘" (v1 명시)
  • 교체 → F5 → 에러 나면 메시지 복붙해서 고쳐줘

  절대경로는 파일 우클릭 → "경로로 복사".

  더 시켜보기 — 폴더 열기 버튼 · 새 핫스트링 · 사이트 여러 개 열기
