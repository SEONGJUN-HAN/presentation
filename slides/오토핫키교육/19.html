클릭 1·2단계. 마우스를 대신 눌러 주기 여는 것 → 누르는 것

지금까지는 여는 것만 했습니다. 에듀파인·메신저처럼 우리가 손댈 수 없는 프로그램은 열고 나서 결국 사람이 눌러야 합니다. 그 클릭을 대신 시킵니다.

계산기를 켜 놓고 해 봅시다

  • Win + R → calc 로 계산기 열기
  • 작업표시줄 H 아이콘 우클릭 → Window Spy
  • 버튼 위에 마우스를 올리면 Screen 좌표가 보입니다
  • 그 숫자를 Click() 안에 넣으면 끝

  실험 — 2단계의 Sleep 을 0 으로 바꿔 보세요. 프로그램이 못 따라와서 두 번째 클릭이 헛나갑니다. 

; 맨 위에 한 번만 — WindowSpy 와 같은 기준
CoordMode "Mouse", "Screen"


; [클릭 1] 한 곳 누르기 : Ctrl + Alt + C
; ▼ 여기만 바꾸세요
^!c::Click(200, 300)


; [클릭 2] 두 곳을 순서대로 : Ctrl + Alt + X
^!x::
{
    Click(200, 300)          ; 첫 번째 자리
    Sleep(300)               ; 0.3초 기다렸다가
    Click(250, 300)          ; 두 번째 자리
}
