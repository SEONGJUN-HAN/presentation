보너스. 좌표 클릭 — WindowSpy & Click 보너스

화면의 아무 곳이나 대신 클릭

  • 계산기를 켜 두고 WindowSpy 실행 (SciTE 메뉴 Tools → Spy)
  • 버튼 위에 마우스 → 화면 좌표(X, Y) 확인
  • 실습 파일 [보너스] 코드 줄 선택 → Ctrl + Q → 좌표 바꿔서 F5

  좌표 클릭은 해상도·창 위치가 바뀌면 깨집니다. Run·Send로 안 될 때만 쓰는 최후의 수단! 

; 클릭 한 번 : Ctrl + Alt + C
^!c::
    CoordMode, Mouse, Screen   ; WindowSpy와 같은 좌표계
    Click, 200 300   ; ← WindowSpy로 본 좌표
Return

; 슬립 넣고 두 번 : Ctrl + Alt + X
^!x::
    CoordMode, Mouse, Screen
    Click, 200 300
    Sleep, 1000
    Click, 250 300
Return
