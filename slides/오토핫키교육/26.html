10단계. 덤 ① 창 다루기 — Alt 와 마우스만으로 지금 눌러보세요

파일 맨 아래에 몇 가지를 더 넣어 뒀습니다. 전부 오늘 배운 것의 확장이라 코드는 안 봐도 됩니다. 단축키만 익히면 됩니다.

🪟 Alt + 마우스

제목표시줄을 안 잡아도, 창 아무 데나 잡고 다룹니다.

Alt + 드래그 창 옮기기
Alt + 우드래그 크기 조절
Alt + 휠 반투명 / 되돌리기
Alt + 가운데클릭 항상 위 켜기/끄기
Alt 두 번 + 클릭 최대화 · 창 닫기
Win + F3 전부 원래대로

  항상 위는 공문 보면서 입력할 때 체감이 제일 큽니다.
