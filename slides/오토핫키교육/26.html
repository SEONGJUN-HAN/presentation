응용 ①. AI를 한글 문서 안으로 공문 다듬기

문장을 드래그하고 단축키 하나면, AI가 공문체로 다듬어 그 자리에 바로 넣어줍니다.

준비는 한 번만

  • aistudio.google.com 에서 무료 API 키 발급 (구글 계정 필요)
  • 옆에 gemini_key.txt 만들고 키 붙여넣기
  • 문장 드래그 → Ctrl + Alt + G

  키를 파일로 분리한 이유 — 스크립트를 남에게 줘도 키가 딸려가지 않습니다. 

; 드래그한 문장을 AI에게 보내고
; 받은 문장으로 그 자리를 교체
^!g::
{
    A_Clipboard := ""      ; 먼저 비우기!
    Send("^c")
    ClipWait(1)

    답 := AskGemini(키, 프롬프트 . A_Clipboard)
    A_Clipboard := 답
    Send("^v")      ; 선택된 문장을 교체
}
