VS Code + AutoHotkey++ 설치

설치 순서

  • 1 code.visualstudio.com 에서 VS Code 설치
  • 2 왼쪽 확장 아이콘 (Ctrl+Shift+X) → AutoHotkey Plus Plus 검색 → 설치
  • 3 .ahk 파일을 VS Code로 열기
  • 4 Ctrl + F9 로 실행  ·  Ctrl + F6 중지

  왜 VS Code인가 — 문법에 색이 입혀지고 오타를 잡아주며, 무엇보다 AI에게 바로 고쳐달라고 할 수 있습니다.

  첫 줄의 #Requires AutoHotkey v2.0 이 "이건 v2입니다" 표시. 이게 있어야 v2로 실행됩니다.
