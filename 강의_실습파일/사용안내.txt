========================================
 오토핫키 실습 파일 사용안내
========================================

[준비]
1) AutoHotkey v1.1 설치 (autohotkey.com → Download → v1.1)
2) 받은 파일들을 아무 폴더에나 함께 둡니다.


==================================================
 A. 직접 만드는 것 (실습 시간에 완성)
==================================================

[1] 내업무도구.ahk  (= 나만의 업무 런처)
- 더블클릭하면 백그라운드에서 대기합니다. Ctrl + Alt + L → 런처 창.
- 슬라이드의 [N단계] = 이 파일의 [N단계] 주석 위치입니다.
- 자신 있으면 빈 파일에 직접 타이핑, 벅차면 이 파일을 열고
  단계 주석을 찾아가며 "여기만 바꾸세요"만 수정하세요.

  [0단계] 워밍업     : Ctrl + Alt + M → 첫 알림창 (확인 후 지워도 됨)
                       → 나중에 런처의 ❓ 도움말 버튼으로 재활용됩니다.
  [1단계] 맛보기 단축키 : Ctrl + Alt + N → 나이스 열기 (핫키 + Run)
  [2단계] 런처 창     : Ctrl + Alt + L → 버튼 모음 창 (Gui)
  [3단계] 버튼 내 것으로 : 버튼 이름과 Run 경로만 교체
                       (경로 따기: 파일 Shift + 우클릭 → "경로로 복사")
  [4단계] 상용구      : /tel, /mail 처럼 영문·숫자 핫스트링
  [5단계] 한글 상용구  : 클립보드로 → /hi, /sign, Ctrl+Alt+1~3
                       (한글을 그냥 타이핑하면 IME 때문에 깨질 수 있음)
  [6단계] 일하는 버튼  : 📝 메모장 열고 할 일 쓰기 (Sleep + Send)
  [보너스] 좌표 클릭   : 코드 줄 선택 → Ctrl + Q 로 켜고 끄기
         · Ctrl+Alt+C : 클릭 한 번 / Ctrl+Alt+X : 슬립 넣고 두 번
         · 계산기를 켜 두고 WindowSpy 로 좌표를 찾아 Click 값을 바꾸세요.

- 바꿀 곳은 전부 "여기만 바꾸세요" 로 표시돼 있습니다.
  그 부분만 내 것으로 채우면 끝입니다.


==================================================
 B. 받아서 바로 쓰는 것 (실습 때는 보기만, 집에서 사용)
==================================================

[3] 통합연락처 (폴더 통째로)
- 우리 모두 같은 메신저를 쓰므로 그대로 작동합니다.
- '담당자DB.csv' 파일만 우리 학교/기관 명단으로 바꾸면 됩니다.
- 메시지 템플릿(설정)도 취향껏 수정 가능.

[4] 이모티콘 (폴더 통째로)
- 이미지를 더블클릭하면 메신저로 바로 전송됩니다.
- 넣을 이미지는 각자 AI로 만들어 폴더에 채워 넣으면 됩니다.


==================================================
 C. 숙제 (참고용)
==================================================

[5] 풀버전 런처 (강사 것, 참고용)
- 인쇄/OCR/PDF/창정렬까지 붙은 완성본입니다.
- 바로 쓰기보다, AI에게 코드를 한 줄씩 물어 뜯어보고
  내 업무에 필요한 버튼만 골라 '내업무도구.ahk'에

==================================================
 공통 안내
==================================================

[수정 방법]
- 파일 우클릭 → "Edit Script" (또는 SciTE로 열기)
- 내용을 바꾼 뒤 저장하고,
  트레이 아이콘 우클릭 → "Reload This Script" 로 즉시 반영.

[한글이 깨져 보이면]
- 이 파일들은 UTF-8 형식으로 저장돼 있습니다.
- SciTE 에서 열었을 때 한글이 깨지면
  메뉴 File → Encoding → UTF-8 을 확인하세요.
