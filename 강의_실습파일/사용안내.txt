========================================
 오토핫키 실습 파일 사용안내
========================================

[준비]
1) AutoHotkey v2 설치 (autohotkey.com → Download → v2.0)
     ※ v1.1 이 아닙니다. 문법이 완전히 다릅니다.
2) VS Code 설치 (code.visualstudio.com)
     → 확장(Ctrl+Shift+X)에서 "AutoHotkey Plus Plus" 검색 후 설치
3) 받은 파일들을 아무 폴더에나 함께 둡니다.

[실행 방법]
- VS Code로 .ahk 파일을 열고  Ctrl + F9  (중지는 Ctrl + F6)
- 또는 파일을 그냥 더블클릭 → 작업표시줄에 초록 H 아이콘이 뜨면 작동 중
- 고친 뒤에는 다시 Ctrl + F9 (또는 H 아이콘 우클릭 → Reload Script)
- WindowSpy(창 이름·좌표 확인) : H 아이콘 우클릭 → Window Spy


==================================================
 A. 직접 만드는 것 (실습 시간에 완성)
==================================================

[1] 내업무도구.ahk  (= 나만의 업무 런처)
- 더블클릭하면 백그라운드에서 대기합니다. Ctrl + Alt + L → 런처 창.
- 슬라이드의 [N단계] = 이 파일의 [N단계] 주석 위치입니다.
- 자신 있으면 빈 파일에 직접 타이핑, 벅차면 이 파일을 열고
  단계 주석을 찾아가며 "여기만 바꾸세요"만 수정하세요.

  [0단계] 워밍업     : Ctrl + Alt + M → 첫 알림창 (확인 후 지워도 됨)
                       → 나중에 런처의 ❓ 도움말 버튼으로 재활용됩니다.
  [1단계] 맛보기 단축키 : Ctrl + Alt + N → 네이버 열기 (핫키 + Run)
  [2단계] 런처 창     : Ctrl + Alt + L → 버튼 모음 창 (Gui)
  [3단계] 버튼 내 것으로 : 버튼 이름과 Run 경로만 교체
                       (경로 따기: 파일 Shift + 우클릭 → "경로로 복사")
  [4단계] 상용구      : /tel, /mail 처럼 영문·숫자 핫스트링
  [5단계] 한글 상용구  : 클립보드로 → /hi, /sign, Ctrl+Alt+1~3
                       (한글을 그냥 타이핑하면 IME 때문에 깨질 수 있음)
  [6단계] 일하는 버튼  : 📝 메모장 열고 할 일 쓰기 (Sleep + Send)
  [보너스] 좌표 클릭   : 코드 줄 선택 → Ctrl + Q 로 켜고 끄기
         · Ctrl+Alt+C : 클릭 한 번 / Ctrl+Alt+X : 슬립 넣고 두 번
         · 계산기를 켜 두고 WindowSpy 로 좌표를 찾아 Click 값을 바꾸세요.

- 바꿀 곳은 전부 "여기만 바꾸세요" 로 표시돼 있습니다.
  그 부분만 내 것으로 채우면 끝입니다.


[2] AI문장다듬기.ahk  (= AI를 한글 문서 안으로)
- 문장을 드래그하고 Ctrl + Alt + G → AI가 공문체로 다듬어 그 자리를 교체합니다.

  준비 (한 번만)
   ① https://aistudio.google.com 접속 → 구글 계정 로그인
   ② "Get API key" 로 무료 키 발급 → 복사
   ③ 이 파일과 같은 폴더에 gemini_key.txt 를 만들고 키만 한 줄 붙여넣고 저장
      (gemini_key.txt.예시 파일의 이름을 gemini_key.txt 로 바꿔 써도 됩니다)

  ※ 키를 파일로 따로 둔 이유
     스크립트를 남에게 줘도 내 API 키가 딸려가지 않습니다.
     남에게 파일을 줄 때 gemini_key.txt 는 빼고 주세요.

  ※ 다듬는 말투를 바꾸고 싶으면
     파일 위쪽 "여기만 바꾸세요 ①" 의 문구를 고치면 됩니다.
     (예: "초등학생도 알아듣게 쉽게" / "더 짧고 간결하게")

[3] 통합연락처 (폴더 통째로)

- 메시지 템플릿(설정)도 취향껏 수정 가능.

[4] 이모티콘 (폴더 통째로)
- 이미지를 더블클릭하면 메신저로 바로 전송됩니다.
- 넣을 이미지는 각자 AI로 만들어 폴더에 채워 넣으면 됩니다.

==================================================
 공통 안내
==================================================

[수정 방법]
- 파일 우클릭 → "Edit script" (또는 VS Code로 열기)
- 내용을 바꾼 뒤 저장하고,
  트레이 아이콘 우클릭 → "Reload This Script" 로 즉시 반영.

[한글이 깨져 보이면]
- 이 파일들은 UTF-8 형식으로 저장돼 있습니다.
- VS Code 에서 열었을 때 한글이 깨지면
  메뉴 File → Encoding → UTF-8 을 확인하세요.
