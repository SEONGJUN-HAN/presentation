========================================
 오토핫키 실습 파일 사용안내
========================================

[준비]
1) AutoHotkey v1.1 설치 (autohotkey.com → Download → v1.1)
2) 받은 파일들을 아무 폴더에나 함께 둡니다.


==================================================
 A. 직접 만드는 것 (실습 시간에 완성)
==================================================

[1] 내업무도구.ahk  (런처 + 상용구가 한 파일에)
- 더블클릭하면 백그라운드에서 대기합니다.
- 이 파일 하나로 세 가지가 됩니다.

  ① 런처   : Ctrl + Alt + L → 창이 뜨고, 버튼으로 실행
  ② 핫스트링 : /tel, /mail 처럼 영문·숫자 상용구 (그냥 하면 됨)
  ③ 클립보드 : 한글 상용구는 클립보드로 → /hi, /sign, Ctrl+Alt+1~3
       (한글을 그냥 타이핑하면 IME 때문에 깨질 수 있어 클립보드 사용)
  ④ (실습용) Click·Sleep·MsgBox — 하나씩 따로 연습
     - 맨 아래에 실습 3개의 코드가 줄마다 ; 로 주석 처리돼 있습니다.
     - 연습할 실습의 "코드 줄"만 마우스로 선택 → Ctrl + Q (주석 해제) → F5.
       끝나면 같은 줄을 선택 → Ctrl + Q 로 다시 주석.
       (Ctrl + Q = 선택한 줄 주석/해제 토글. 한 번에 하나씩만 켜세요.)
         · 실습1 (Ctrl+Alt+C) : 클릭 한 번
         · 실습2 (Ctrl+Alt+X) : 슬립 넣고 클릭 두 번
         · 실습3 (Ctrl+Alt+M) : 메시지 박스
     - 계산기를 미리 켜 두고 WindowSpy 로 버튼 좌표를 찾아 Click 값을 바꾸세요.

- 바꿀 곳은 전부 "여기만 바꾸세요" 로 표시돼 있습니다.
  그 부분만 내 것으로 채우면 끝입니다.


==================================================
 B. 받아서 바로 쓰는 것 (실습 때는 보기만, 집에서 사용)
==================================================

[3] 통합연락처 (폴더 통째로)
- 우리 모두 같은 메신저를 쓰므로 그대로 작동합니다.
- '담당자DB.csv' 파일만 우리 학교/기관 명단으로 바꾸면 됩니다.
- 메시지 템플릿(설정)도 취향껏 수정 가능.

[4] 이모티콘 (폴더 통째로)
- 이미지를 더블클릭하면 메신저로 바로 전송됩니다.
- 넣을 이미지는 각자 AI로 만들어 폴더에 채워 넣으면 됩니다.


==================================================
 C. 숙제 (참고용)
==================================================

[5] 풀버전 런처 (강사 것, 참고용)
- 인쇄/OCR/PDF/창정렬까지 붙은 완성본입니다.
- 바로 쓰기보다, AI에게 코드를 한 줄씩 물어 뜯어보고
  내 업무에 필요한 버튼만 골라 '내업무도구.ahk'에
  옮겨 붙이며 업그레이드해 보는 용도입니다.


==================================================
 공통 안내
==================================================

[수정 방법]
- 파일 우클릭 → "Edit Script" (또는 SciTE로 열기)
- 내용을 바꾼 뒤 저장하고,
  트레이 아이콘 우클릭 → "Reload This Script" 로 즉시 반영.

[한글이 깨져 보이면]
- 이 파일들은 UTF-8 형식으로 저장돼 있습니다.
- SciTE 에서 열었을 때 한글이 깨지면
  메뉴 File → Encoding → UTF-8 을 확인하세요.
