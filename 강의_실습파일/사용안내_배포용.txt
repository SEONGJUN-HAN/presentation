========================================================
  오토핫키 업무자동화 연수 — 배포 폴더 사용 안내
========================================================

■ 먼저 할 일 (한 번만)

  1) 이 폴더를 통째로 내 PC로 복사합니다.
     - 바탕화면이든 D드라이브든 어디든 상관없습니다.
     - 단, 폴더 안의 파일들을 따로따로 떼어내지는 마세요.
       내업무도구.ahk 가 옆의 '도구' 폴더를 찾아서 쓰기 때문입니다.

  2) AutoHotkey v2 가 설치돼 있어야 합니다.
     - www.autohotkey.com → Download → v2.0
     - 이미 설치했다면 넘어가세요.

  3) 내업무도구.ahk 를 더블클릭합니다.
     - 작업표시줄 오른쪽에 H 아이콘이 생기면 실행된 것입니다.


■ 두 개의 런처

  Ctrl + Alt + L            기본형 — 연수 때 직접 만든 것
                            버튼 몇 개짜리. 파일 윗부분을 고치면 바뀝니다.

  Ctrl + Alt + Shift + L    실전형 — 미리 만들어 둔 것
                            이 폴더의 프로그램들이 이미 연결돼 있습니다.
                            창이 뜨면 Alt + 괄호 안 글자로 바로 실행됩니다.


■ 그 밖에 들어 있는 것 (파일 아래쪽 [10]·[11]단계)

  Alt + 드래그 / 우드래그   창 옮기기 / 크기 조절
  Alt + 휠 / 가운데클릭     반투명 / 항상 위
  Alt 두 번 + 클릭          최대화 · 창 닫기
  Win + F3                  투명도·항상위 전부 해제
  Win + 숫자패드 1~9        화면을 9칸으로 나눠 그 자리로
  Ctrl + Shift + C / V      서식 없이 복사 / 붙여넣기
  Ctrl + Alt + H            단축키·상용구 목록 (파일을 읽어 자동 생성)

  /ad  메일 한 통 통째로     /sg  서명만      /gr  첫인사만
  /rq  협조 요청 문구        /fw  붙임 안내   /dt  오늘 날짜
  //1  ①  (//2 //3 …)

  ※ 이름·학교·연락처는 파일 아래쪽 '내 정보' 여섯 줄만 바꾸면
     인사말과 서명에 한꺼번에 반영됩니다.


■ 클릭 실습 (마우스를 대신 눌러 주기)

  Ctrl + Alt + C   한 곳 누르기        (좌표를 내 것으로 바꾸고 쓰세요)
  Ctrl + Alt + X   두 곳을 순서대로
  Ctrl + Alt + V   그림을 찾아서 누르기

  좌표 보는 법 : 작업표시줄 H 아이콘 우클릭 → Window Spy
                 버튼 위에 마우스를 올리면 Screen 좌표가 보입니다.

  그림 만드는 법 : Win + Shift + S 로 버튼만 자르기
                 → Win + R → mspaint → Ctrl + V → Ctrl + S
                 → '클릭이미지' 폴더에 PNG 로 저장
                 → 그 파일 Shift + 우클릭 → "경로로 복사"
                 → 내업무도구.ahk 의 따옴표 안에 붙여넣기

  ※ 배경이 투명한 PNG 는 못 찾습니다. 그림판으로 저장하세요.
  ※ 화면 배율이 다른 PC 에서 만든 그림도 안 맞습니다.
     그림은 반드시 내 PC 에서 내가 캡처해야 합니다.
  ※ 자세한 것은 '클릭이미지' 폴더의 읽어보세요.txt 참고.


■ 폴더 안에 뭐가 있나

  내업무도구.ahk       윗부분 = 배우는 곳 / 아랫부분 = 쓰는 곳
  도구\                한글 서식도우미 · PDF·한글 문서정리 도우미
                       간단 도구 모음(계산기·추첨·텍스트 비교·QR)
                       이미지 용량 줄이기
  도구\PY\             파이썬 프로그램 (아래 '숙제' 참고)
  클릭이미지\          클릭 3단계에서 내가 캡처한 버튼 그림을 넣는 곳
  이모티콘\            메신저에 붙여넣는 이미지 (이모티콘.ahk 실행)
  통합연락처\          메신저 쪽지 자동 발송


■ 내 것으로 바꾸기

  · 내업무도구.ahk 를 VS Code(또는 메모장)로 엽니다.
  · "▼ 여기만 바꾸세요" 라고 적힌 곳만 고칩니다.
  · 경로는 파일을 Shift + 우클릭 → "경로로 복사" 로 따서 붙여넣습니다.
  · 고친 뒤에는 트레이의 H 아이콘 우클릭 → Reload This Script.

  막히면 파일 내용을 통째로 복사해서 AI에게 붙여넣고
  "AutoHotkey v2 인데 여기에 ○○ 여는 버튼 하나 추가해줘" 라고 시키세요.
  에러가 나면 빨간 창의 글자를 그대로 복사해서 "이 오류 고쳐줘".


■ 숙제 — PY 버튼 살리기

  런처 오른쪽 아래 "PY" 가 붙은 버튼 세 개는 지금 눌러도 안 열립니다.
  파이썬으로 만든 프로그램이라, 파이썬이 깔려 있어야 하기 때문입니다.

    PY  PDF 페이지 번호     PDF 아래에 쪽 번호 찍기
    PY  PDF 마스킹 출력     가릴 부분을 칠해서 출력
    PY  마트 계산기         단가 비교 계산기

  파이썬을 깔고, 프로그램마다 필요한 것을 더 설치하면 그때부터 열립니다.
  어떻게 하는지는 AI 에게 물어보세요. 그게 이번 숙제입니다.

  ※ 왜 굳이 파이썬이냐 —
     AI 에게 "이런 프로그램 만들어줘" 라고 시킬 때 가장 잘 통하는 게
     파이썬입니다. 한 번 깔아두면 시킬 수 있는 범위가 확 넓어집니다.

■ 자주 묻는 것

  Q. 부팅할 때마다 자동으로 켜지게 하려면?
     Win + R → shell:startup → 내업무도구.ahk 의 '바로가기'를 넣어 두세요.
     (원본이 아니라 바로가기를 넣어야 파일을 고쳐도 최신 내용이 반영됩니다)

  Q. 단축키가 다른 프로그램과 겹칩니다.
     파일에서 ^!l 처럼 생긴 부분을 다른 글자로 바꾸면 됩니다.
     ^ = Ctrl, ! = Alt, + = Shift, # = Win

  Q. 버튼을 눌렀더니 "경로가 없습니다" 라고 뜹니다.
     그 파일이 있어야 할 자리에 없다는 뜻입니다.
     메시지에 적힌 경로를 보고 내 PC의 실제 경로로 고쳐 주세요.
